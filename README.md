
  # The Candle Studio Co. — one-page website

  A single-page site for The Candle Studio Co., a UK handmade candle business.
  The top navigation anchor-links down to each product category section.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Adding a new product category

  Add an entry to the `categories` array in `src/data/categories.ts` (name,
  description, products with prices, optional notes/safety copy, and any
  product images). The navigation, footer links and page sections are all
  generated from this list automatically.
